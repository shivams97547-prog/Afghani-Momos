# 🥟 Afghani Momos — Taste Ka Baap!

A modern and responsive food website designed for Afghani Momos, featuring an attractive user interface, smooth animations, and a delicious food-themed experience.

## 🌟 Features

- Modern and attractive website design
- Responsive layout for different screen sizes
- Smooth animations and visual effects
- Food-inspired user interface
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 Project Preview

Explore the website to experience its design and animations.

## 🎯 Project Goal

The goal of this project is to create an engaging online presence for a local momos business and provide visitors with an enjoyable browsing experience.
